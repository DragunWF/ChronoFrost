# Contribution Guide

Please follow these steps when contributing to the project.

---

## 1. Create an Issue

1. Go to the **Issues** tab of the repository.
2. Click **New Issue**.
3. Write a clear and descriptive **title**.
4. Provide a short **description** of the problem, task, or feature.
5. Add labels if applicable (bug, feature, enhancement, etc.).
6. Assign the issue if necessary.
7. Submit the issue.

---

## 2. Create a Branch

1. Ensure your branch is based on the latest **main** branch.
2. Create a new branch for the issue.

**Branch naming format**

- `feature/issue-number-short-description`
- `fix/issue-number-short-description`
- `chore/issue-number-short-description`

**Example**

- `feature/12-add-login-validation`

---

## 3. Implement the Changes

1. Work on the assigned issue.
2. Ensure the implementation follows the project’s coding standards.
3. Test your changes before submitting.

---

## 4. Commit Changes

1. Write clear and descriptive commit messages.
2. Keep commits focused and related to the issue.

**Example**

- `feat: add login validation`
- `fix: resolve API response error`

---

## 5. Create a Pull Request

1. Open a **Pull Request** from your branch to the **main** branch.
2. Add a clear and descriptive **title**.
3. Include a short description explaining the changes.
4. Link the related issue in the description.
5. Submit the Pull Request.

---

## 6. Review and Merge

1. Wait for maintainers to review the Pull Request.
2. Address any feedback or requested changes.
3. Once approved, the Pull Request will be merged into **main**.

---

✅ Keep Pull Requests small and focused on a single issue.
